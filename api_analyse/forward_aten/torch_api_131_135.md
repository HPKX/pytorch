## 备注

- `aten::_transformer_encoder_layer_fwd` 和 `aten::_native_multi_head_attention` 在 Autograd key 上是 `autogradNotImplementedFallback()`；Python 前端只在推理条件满足时进入这些 fused 路径。
- `TransformerDecoderLayer` 没有整层 fused ATen op；其 dispatch 主要来自两个 `MultiheadAttention` 子块和 FFN。
- `F.affine_grid` 的直接前向入口是 `aten::affine_grid_generator`，不是 `aten::cudnn_affine_grid_generator`。
