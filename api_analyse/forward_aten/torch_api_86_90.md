# torch API 86-90 ATen Dispatch 分析

| 接口 | 场景 | ATen Dispatch 调用链 | 正向 Dispatch 依赖的 ATen 接口 |
| --- | --- | --- | --- |
| `torch.nn.AvgPool1d` | 普通前向 / `input.requires_grad=True` | `nn.AvgPool1d.forward` -> `F.avg_pool1d` -> `torch.avg_pool1d` -> `aten::avg_pool1d` -> `CompositeImplicitAutograd(native::avg_pool1d)` -> `aten::unsqueeze` -> `aten::avg_pool2d` -> `Autograd(VariableType::avg_pool2d)` -> CPU/CUDA/MPS structured wrapper（由 `avg_pool2d.out` codegen 生成） -> backend pooling kernel -> `aten::squeeze` | `aten::avg_pool1d`<br>`aten::unsqueeze`<br>`aten::avg_pool2d`<br>`aten::squeeze` |
| `torch.nn.CELU` | 默认 `inplace=False`，关注梯度 | `nn.CELU.forward` -> `F.celu` -> `torch.celu` -> `aten::celu` -> `CompositeExplicitAutograd(native::celu)` -> `aten::elu` -> `Autograd(VariableType::elu)` -> backend wrapper -> `elu_stub` -> CPU/CUDA kernel | `aten::celu`<br>`aten::elu` |
| `torch.nn.CTCLoss` | 普通 CPU / 未命中加速后端 | `nn.CTCLoss.forward` -> `F.ctc_loss` -> `torch.ctc_loss` -> `aten::ctc_loss.IntList` / `aten::ctc_loss.Tensor` -> `CompositeImplicitAutograd(native::ctc_loss)` -> `aten::_ctc_loss` -> `Autograd(VariableType::_ctc_loss/_ctc_loss.Tensor)` -> CPU/CUDA backend wrapper -> `ctc_loss_cpu` / `ctc_loss_gpu` -> reduction（`mean/sum/none`） | `aten::ctc_loss.IntList`<br>`aten::ctc_loss.Tensor`<br>`aten::_ctc_loss` |
| `torch.nn.CTCLoss` | CUDA 命中 cuDNN / MIOpen 加速 | `nn.CTCLoss.forward` -> `F.ctc_loss` -> `torch.ctc_loss` -> `aten::ctc_loss.IntList` / `aten::ctc_loss.Tensor` -> `CompositeImplicitAutograd(native::ctc_loss)` -> `aten::_use_cudnn_ctc_loss` / `aten::_use_miopen_ctc_loss` -> `aten::_cudnn_ctc_loss` 或 `aten::miopen_ctc_loss` -> 专用 backend 实现 -> reduction | `aten::ctc_loss.IntList`<br>`aten::ctc_loss.Tensor`<br>`aten::_use_cudnn_ctc_loss`<br>`aten::_use_miopen_ctc_loss`<br>`aten::_cudnn_ctc_loss`<br>`aten::miopen_ctc_loss` |
| `torch.nn.ChannelShuffle` | CPU 普通张量 | `nn.ChannelShuffle.forward` -> `F.channel_shuffle` -> `torch.channel_shuffle` -> `aten::channel_shuffle` -> `Autograd(VariableType::channel_shuffle)` -> CPU wrapper -> `native::channel_shuffle` -> `aten::native_channel_shuffle` -> CPU wrapper -> `native::channel_shuffle_cpu` -> `channel_shuffle_kernel` -> `channel_shuffle_kernel_impl` | `aten::channel_shuffle`<br>`aten::native_channel_shuffle` |
| `torch.nn.ChannelShuffle` | CUDA 张量 | `nn.ChannelShuffle.forward` -> `F.channel_shuffle` -> `torch.channel_shuffle` -> `aten::channel_shuffle` -> `Autograd(VariableType::channel_shuffle)` -> CUDA wrapper -> `native::channel_shuffle` -> `aten::native_channel_shuffle` -> `CompositeImplicitAutograd(math_channel_shuffle)` -> `aten::view` -> `aten::permute` -> `aten::contiguous` -> `aten::reshape` | `aten::channel_shuffle`<br>`aten::native_channel_shuffle`<br>`aten::view`<br>`aten::permute`<br>`aten::contiguous`<br>`aten::reshape` |
| `torch.nn.ConvTranspose1d` | 常见实数输入，`requires_grad=True` | `nn.ConvTranspose1d.forward` -> `self._output_padding(...)` -> `F.conv_transpose1d` -> `torch.conv_transpose1d` -> `aten::conv_transpose1d` -> `CompositeImplicitAutograd(native::conv_transpose1d_symint)` -> `aten::convolution`（`transposed=true`） -> `Autograd(derivatives on convolution)` -> `CompositeExplicitAutograd(native::convolution)` -> `aten::_convolution` -> `CompositeExplicitAutograd(native::_convolution)` -> backend-specific convolution-transpose impl（cuDNN/MIOpen/MPS/slow 等） | `aten::conv_transpose1d`<br>`aten::convolution`<br>`aten::_convolution` |
