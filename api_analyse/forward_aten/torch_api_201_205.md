# torch API 201-205 ATen Dispatch 分析

## 备注

- `torch.tanhshrink` 在这份 repo 里没有独立的 generated `aten::tanhshrink` 前向入口；实际前向实现就是 `input - input.tanh()`，所以应按两个内部 ATen hop 展开。
- `tensor_split`、`tensordot`、`trapezoid` 在 `VariableTypeEverything.cpp` 中都没有专门的前向 autograd 注册，前向走 `CompositeImplicitAutograd`，梯度由内部 `slice`、`sum`、`mm`、`dot`、`mul` 等算子承担。
- `tril_indices` 在 autograd 层注册的是 `autogradNotImplementedFallback()`；它本身是无 Tensor 输入的 factory 路径，前向核心分派仍是 `BackendSelect -> backend kernel`。
