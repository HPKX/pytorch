# torch API 166-170 ATen Dispatch 分析

| `torch.nn.modules.flatten.Unflatten` | NamedTensor，`dim` 为 `str` | `Unflatten.forward -> input.unflatten(...) -> aten::unflatten.Dimname`(CompositeImplicitAutograd) `-> native::unflatten_dimname_symint -> native::unflatten_impl -> aten::view`；随后仅做内部名字写回，不再进入新的 ATen op | `aten::unflatten.Dimname`, `aten::view` |

## 备注

- `torch.optim.ASGD`、`Adamax`、`RMSprop` 都不是“一个 Python API 对应一个 ATen schema”，而是 `step()` 在 Python 中串联多个 ATen 原语；默认 `differentiable=False` 时这些更新通常运行在 `no_grad` 语义下，`foreach` 路径也显式不支持 autograd。
- `Adamax` 在 `differentiable=True` 的单张量分支里，`exp_inf` 更新会从 `aten::maximum.out` 改成 `aten::cat -> aten::amax`。
- `torch.numel` 的 eager Python 路径是少数显式绕开 dispatcher 的 API。
