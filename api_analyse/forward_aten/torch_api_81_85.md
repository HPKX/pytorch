# torch API 81-85 ATen Dispatch 分析

| 接口 | 场景 | ATen Dispatch 调用链 | 正向 Dispatch 依赖的 ATen 接口 |
| --- | --- | --- | --- |
| `torch.mvlgamma` | dense Tensor，`out=None`；整数输入会先升到默认浮点；`requires_grad` 时先过 Autograd | `torch.mvlgamma` / `Tensor.mvlgamma` -> `aten::mvlgamma` -> `Autograd{backend}` -> `CompositeExplicitAutograd(mvlgamma)` -> `at::native::mvlgamma` -> `aten::arange.start_step` -> `aten::unsqueeze` -> `aten::add.Tensor` -> `aten::lgamma_` -> `aten::sum.dim_IntList` -> `aten::add_.Scalar` | `aten::mvlgamma`、`aten::arange.start_step`、`aten::unsqueeze`、`aten::add.Tensor`、`aten::lgamma_`、`aten::sum.dim_IntList`、`aten::add_.Scalar` |
| `torch.nanmean` | floating / complex Tensor，`out=None`；顶层本身无专门 Autograd wrapper，梯度来自内部 ATen op | `torch.nanmean` / `Tensor.nanmean` -> `aten::nanmean` -> `CompositeImplicitAutograd(nanmean)` -> `at::native::nanmean` -> 因子分支: `aten::detach` -> `aten::isnan` -> `aten::logical_not_` -> `aten::sum.dim_IntList`；数值分支: `aten::nansum` -> `Autograd{backend}` -> `CPU/CUDA/MPS` nansum backend -> `at::native::nansum{,_mps}` -> `nansum_stub`(CPU/CUDA) / MPS impl -> `aten::div.Tensor` | `aten::nanmean`、`aten::detach`、`aten::isnan`、`aten::logical_not_`、`aten::sum.dim_IntList`、`aten::nansum`、`aten::div.Tensor` |
| `torch.nanmedian` | 全 Tensor 归约：`torch.nanmedian(input)` | `torch.nanmedian` / `Tensor.nanmedian()` -> `aten::nanmedian` -> `Autograd{backend}` -> `CPU/CUDA/MPS` backend -> `at::native::nanmedian_{cpu/cuda/mps}` -> CPU/CUDA 内部 helper `median_impl(ignore_nan=true)` / MPS `median_common_mps(..., true)` | `aten::nanmedian` |
| `torch.nanmedian` | 按维归约：`torch.nanmedian(input, dim, keepdim=...)` | `torch.nanmedian` / `Tensor.nanmedian(dim, keepdim)` -> `aten::nanmedian.dim` -> `Autograd{backend}` -> `CompositeExplicitAutograd(nanmedian.dim)` -> `at::native::nanmedian` -> `aten::empty`(values) + `aten::empty`(indices) -> `aten::nanmedian.dim_values` -> `CPU/CUDA/MPS` backend `nanmedian_out_{cpu/cuda/mps}` | `aten::nanmedian.dim`、`aten::empty`、`aten::nanmedian.dim_values` |
| `torch.nextafter` | 浮点 Tensor，`out=None`；若 `requires_grad`，Autograd 会包装但 backward 在 `derivatives.yaml` 中是 `not_implemented("nextafter")` | `torch.nextafter` / `Tensor.nextafter` -> `aten::nextafter` -> `Autograd{backend}` -> `CPU/CUDA/MPS` structured wrapper -> `meta(nextafter)` + `impl(nextafter_out)` -> `nextafter_stub` -> `nextafter_kernel` / `nextafter_kernel_cuda` / `nextafter_mps_kernel`。`structured_delegate: nextafter.out` 只是 codegen 关系，不是 runtime hop | `aten::nextafter` |
| `torch.nn.AdaptiveMaxPool3d` | `return_indices=False` 默认路径；模块最终只返回 output，但底层仍会算出 indices | `nn.AdaptiveMaxPool3d.forward` -> `F.adaptive_max_pool3d` -> `boolean_dispatch(if_false=_adaptive_max_pool3d)` -> `adaptive_max_pool3d_with_indices(...)[0]` -> `torch._C._nn.adaptive_max_pool3d` -> `aten::adaptive_max_pool3d` -> `Autograd{backend}` -> `CPU/CUDA` structured wrapper -> `meta(adaptive_max_pool3d)` + `impl(adaptive_max_pool3d_out_{cpu/cuda})` | `aten::adaptive_max_pool3d` |
| `torch.nn.AdaptiveMaxPool3d` | `return_indices=True`；模块直接返回 `(output, indices)` | `nn.AdaptiveMaxPool3d.forward` -> `F.adaptive_max_pool3d` -> `boolean_dispatch(if_true=adaptive_max_pool3d_with_indices)` -> `torch._C._nn.adaptive_max_pool3d` -> `aten::adaptive_max_pool3d` -> `Autograd{backend}` -> `CPU/CUDA` structured wrapper -> `meta(adaptive_max_pool3d)` + `impl(adaptive_max_pool3d_out_{cpu/cuda})` | `aten::adaptive_max_pool3d` |

## 备注

- `torch.nanmean` 在 dispatcher 顶层是 `CompositeImplicitAutograd`，没有单独的 `VariableType` 包装；真正记录梯度的是内部的 `aten::nansum` 和后续 `aten::div.Tensor`。
- `torch.nn.AdaptiveMaxPool3d` 的训练反向会调用 `aten::adaptive_max_pool3d_backward`；它同样是 structured op，runtime 直接走 `meta(adaptive_max_pool3d_backward)` + `impl(adaptive_max_pool3d_backward_out_{cpu/cuda})`，不是先 runtime 再跳一次 `structured_delegate`。
