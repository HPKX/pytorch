## 备注

- `Rprop`、`Adadelta`、`Adagrad` 都不是“一个前端接口对应一个 ATen schema”，而是 `step()` 在 Python 中串联多条 ATen 原语；`foreach=True` 时会切到 batched `_foreach_`* 原语，`differentiable=False` 时通常工作在 `no_grad` 语义下。
- `CosineAnnealingWarmRestarts` 是纯 Python 学习率调度逻辑，不存在稳定的单一 ATen dispatch 链。
- `torch.orgqr` 在当前代码里只是 `torch.linalg.householder_product` 的别名；真正的后端计算通过 `orgqr_stub` 落到 CPU LAPACK / CUDA cuSOLVER。
