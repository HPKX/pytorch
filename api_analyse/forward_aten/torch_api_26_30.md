# torch API 26-30 ATen Dispatch 分析

| 接口 | 场景 | ATen Dispatch 调用链 | 正向 Dispatch 依赖的 ATen 接口 |
| --- | --- | --- | --- |
| `torch.cov` | 稠密 1D/2D 浮点或复数输入；带 `fweights/aweights` 的加权路径最完整，`requires_grad` 时梯度来自内部算子而不是 `aten::cov` 本身 | `torch.cov` -> `aten::cov` -> `CompositeImplicitAutograd`(`native::cov`，无专门 `VariableType` 包装) -> `{1D 输入: aten::view({1, -1})}` -> `{加权: aten::mul` 组合权重，`aten::sum`/`aten::scalar_tensor` 求 `w_sum`}` -> `aten::unsqueeze` + `aten::sub` 做中心化 -> `aten::t` + `aten::conj` + `aten::mm` 求协方差矩阵 -> `{复数单变量特例: aten::real + aten::zeros_like + aten::complex}` -> `aten::true_divide` -> `aten::squeeze` | `aten::cov`<br>`aten::view`<br>`aten::mul`<br>`aten::sum`<br>`aten::scalar_tensor`<br>`aten::unsqueeze`<br>`aten::sub`<br>`aten::t`<br>`aten::conj`<br>`aten::mm`<br>`aten::real`<br>`aten::zeros_like`<br>`aten::complex`<br>`aten::true_divide`<br>`aten::squeeze` |
| `torch.deg2rad` | 稠密实数张量；`requires_grad=True` 会走专门 autograd 包装，整型输入会先提升到默认浮点 dtype | `torch.deg2rad` -> `aten::deg2rad` -> `[requires_grad] AutogradCPU/CUDA`(`Deg2RadBackward0`) -> `CompositeExplicitAutograd`(`native::deg2rad`) -> `aten::empty_like`(必要时改成默认浮点 dtype) -> 真实 runtime hop `aten::deg2rad.out` -> `CompositeExplicitAutograd`(`native::deg2rad_out`) -> `aten::mul.out(self, wrapped_scalar_tensor(pi/180))` | `aten::deg2rad`<br>`aten::empty_like`<br>`aten::deg2rad.out`<br>`aten::mul.out` |
| `torch.diag_embed` | 稠密输入，常见于 batched diagonal matrix；`requires_grad=True` 时有专门 backward | `torch.diag_embed` -> `aten::diag_embed` -> `[requires_grad] AutogradCPU/CUDA`(`DiagEmbedBackward0`) -> `CompositeExplicitAutogradNonFunctional`(`native::diag_embed`) -> `aten::zeros` 分配结果 -> 真实 runtime hop `aten::diagonal`(`CompositeExplicitAutograd`/`native::diagonal` -> `aten::as_strided` view) -> `aten::copy_` 写入对角线<br>backward: `grad_self = aten::diagonal(grad, offset, dim1, dim2)` | `aten::diag_embed`<br>`aten::zeros`<br>`aten::diagonal`<br>`aten::as_strided`<br>`aten::copy_` |
| `torch.diagflat` | 任意形状输入；会先 flatten，再走“1D `diag` -> `diag_embed`”路径；顶层无专门 autograd 包装 | `torch.diagflat` -> `aten::diagflat` -> `CompositeImplicitAutograd`(`native::diagflat`) -> `aten::contiguous` -> `aten::view(-1)` -> 真实 runtime hop `aten::diag` -> `CompositeImplicitAutograd`(`native::diag`) -> 由于 flatten 后恒为 1D，走 1D 分支到 `aten::diag_embed` -> `CompositeExplicitAutogradNonFunctional`(`native::diag_embed`) -> `aten::zeros` -> `aten::diagonal`(`aten::as_strided` view) -> `aten::copy_` | `aten::diagflat`<br>`aten::contiguous`<br>`aten::view`<br>`aten::diag`<br>`aten::diag_embed`<br>`aten::zeros`<br>`aten::diagonal`<br>`aten::as_strided`<br>`aten::copy_` |
| `torch.diagonal` | 标准位置参数 overload；返回 view，`requires_grad=True` 时最能看清 view-op 的 autograd 链 | `torch.diagonal` -> `aten::diagonal` -> `[requires_grad] AutogradCPU/CUDA`(`DiagonalBackward0`，保存 `self.sym_sizes/offset/dim1/dim2`) -> `CompositeExplicitAutograd`(`native::diagonal`) -> `aten::as_strided` view<br>backward: `aten::diagonal_backward` -> `CompositeExplicitAutograd`(`native::diagonal_backward_symint`) -> `aten::zeros` -> `aten::diagonal` -> `aten::copy_` | `aten::diagonal`<br>`aten::as_strided` |
