# torch API 91-95 ATen Dispatch 分析

| 接口 | 场景 | ATen Dispatch 调用链 | 正向 Dispatch 依赖的 ATen 接口 |
| --- | --- | --- | --- |
| `torch.nn.ConvTranspose3d` | 标准前向；batched 实数输入；常见 CPU/CUDA 路径 | `nn.ConvTranspose3d.forward` -> `torch.nn.functional.conv_transpose3d`（即 `torch.conv_transpose3d`）-> `aten::conv_transpose3d.input` -> `CompositeImplicitAutograd` -> `at::native::conv_transpose3d_symint` -> `aten::convolution` -> 内部卷积后端选择 -> CUDA 常见落到 `aten::cudnn_convolution_transpose`，ROCm 常见落到 `aten::miopen_convolution_transpose`，CPU/回退可落到 `aten::slow_conv_transpose3d` | `aten::conv_transpose3d.input`, `aten::convolution`, `aten::cudnn_convolution_transpose`, `aten::miopen_convolution_transpose`, `aten::slow_conv_transpose3d` |
| `torch.nn.ConvTranspose3d` | 非 batched 输入 `(C,D,H,W)` | `nn.ConvTranspose3d.forward` -> `aten::conv_transpose3d.input` -> `CompositeImplicitAutograd` -> `at::native::conv_transpose3d_symint` 内部先 `batchify`，计算后对结果做 `squeeze(0)`；后端主干仍经 `aten::convolution` -> 具体 backend kernel | `aten::conv_transpose3d.input`, `aten::convolution` |
| `torch.nn.Dropout1d` | 标准训练态；batched `(N,C,L)` | `nn.Dropout1d.forward` -> `torch.nn.functional.dropout1d` -> `aten::feature_dropout` -> `CompositeImplicitAutograd` -> `at::native::feature_dropout` -> `input.new_empty_symint` 构造 channel mask -> `aten::bernoulli_` -> `aten::div_` -> `aten::mul.Tensor` | `aten::feature_dropout`, `aten::new_empty`, `aten::bernoulli_`, `aten::div_`, `aten::mul.Tensor` |
| `torch.nn.Dropout1d` | 非 batched `(C,L)` | `nn.Dropout1d.forward` -> `torch.nn.functional.dropout1d` -> Python 侧先 `aten::unsqueeze` 补 batch 维 -> `aten::feature_dropout` -> `CompositeImplicitAutograd` -> `at::native::feature_dropout` -> `aten::bernoulli_` -> `aten::div_` -> `aten::mul.Tensor` -> 返回前 `aten::squeeze` | `aten::unsqueeze`, `aten::feature_dropout`, `aten::bernoulli_`, `aten::div_`, `aten::mul.Tensor`, `aten::squeeze` |
| `torch.nn.Dropout2d` | 标准训练态；4D `(N,C,H,W)` | `nn.Dropout2d.forward` -> `torch.nn.functional.dropout2d` -> `aten::feature_dropout` -> `CompositeImplicitAutograd` -> `at::native::feature_dropout` -> `input.new_empty_symint` 构造 channel mask -> `aten::bernoulli_` -> `aten::div_` -> `aten::mul.Tensor` | `aten::feature_dropout`, `aten::new_empty`, `aten::bernoulli_`, `aten::div_`, `aten::mul.Tensor` |
| `torch.nn.Dropout3d` | 标准训练态；batched `(N,C,D,H,W)` | `nn.Dropout3d.forward` -> `torch.nn.functional.dropout3d` -> `aten::feature_dropout` -> `CompositeImplicitAutograd` -> `at::native::feature_dropout` -> `input.new_empty_symint` 构造 channel mask -> `aten::bernoulli_` -> `aten::div_` -> `aten::mul.Tensor` | `aten::feature_dropout`, `aten::new_empty`, `aten::bernoulli_`, `aten::div_`, `aten::mul.Tensor` |
| `torch.nn.Dropout3d` | 非 batched `(C,D,H,W)` | `nn.Dropout3d.forward` -> `torch.nn.functional.dropout3d` -> Python 侧先 `aten::unsqueeze` -> `aten::feature_dropout` -> `CompositeImplicitAutograd` -> `at::native::feature_dropout` -> `aten::bernoulli_` -> `aten::div_` -> `aten::mul.Tensor` -> 返回前 `aten::squeeze` | `aten::unsqueeze`, `aten::feature_dropout`, `aten::bernoulli_`, `aten::div_`, `aten::mul.Tensor`, `aten::squeeze` |
| `torch.nn.GRU` | 普通 dense 输入；未打包序列 | `nn.GRU.forward` -> `_VF.gru` -> `aten::gru.input` -> `CompositeImplicitAutograd` -> `at::native::gru(input, ...)` -> CUDA 常见走 `gru_cudnn_stub` -> `aten::_cudnn_rnn`；ROCm 常见走 `gru_miopen_stub` -> `aten::miopen_rnn`；CPU/回退走 `_rnn_impl_with_concat` -> `GRUCell` -> `aten::linear` / `aten::_thnn_fused_gru_cell`，或拆成 `aten::sigmoid_`、`aten::tanh_`、`aten::mul_`、`aten::add_` | `aten::gru.input`, `aten::_cudnn_rnn`, `aten::miopen_rnn`, `aten::linear`, `aten::_thnn_fused_gru_cell`, `aten::sigmoid_`, `aten::tanh_`, `aten::mul_`, `aten::add_` |
| `torch.nn.GRU` | `PackedSequence` 输入 | `nn.GRU.forward` -> `_VF.gru` -> `aten::gru.data` -> `CompositeImplicitAutograd` -> `at::native::gru(data, batch_sizes, ...)` -> packed CUDA 路径走 `gru_packed_cudnn_stub` -> `aten::_cudnn_rnn`，ROCm 路径走 `gru_packed_miopen_stub` -> `aten::miopen_rnn`，CPU/回退则进入 packed `_rnn_impl_with_concat` | `aten::gru.data`, `aten::_cudnn_rnn`, `aten::miopen_rnn` |

## 备注

- `torch.nn.Dropout1d`、`torch.nn.Dropout2d`、`torch.nn.Dropout3d` 的模块前向最终都落到 `aten::feature_dropout`，不是 `aten::dropout` / `aten::native_dropout`。
- `aten::gru.input`、`aten::gru.data`、`aten::conv_transpose3d.input` 前向入口本身走 `CompositeImplicitAutograd`；梯度分别由内部 RNN fast-path/fallback 算子或卷积内部实际算子承担。
