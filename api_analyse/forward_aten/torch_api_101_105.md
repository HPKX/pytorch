## 备注

- `InstanceNorm1d/2d/3d` 的核心 ATen 路径相同，只是模块侧允许的输入维度不同。若输入是无 batch 形态，模块会先做 `aten::unsqueeze(0)`，归一化后再 `aten::squeeze(0)`。
- `instance_norm` 本身是 `CompositeImplicitAutograd` 包装，没有单独的手写 autograd wrapper；梯度主要继承自内部 `batch_norm` 相关 ATen 路径。
- 若 `track_running_stats=True` 且 `running_mean/running_var` 已定义，`at::native::instance_norm` 在 `batch_norm` 后还会额外走 `aten::alias`、`aten::view`、`aten::mean`、`aten::copy_` 来回写统计量。
- `LPPool1d/2d` 没有独立的 `aten::lp_pool1d/2d`，它们是 Python 层组合算子；autograd 也由内部 `pow`、`avg_pool2d`、`relu` 等算子继承。
