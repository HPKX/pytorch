# torch API 211 ATen Dispatch 分析


| 接口             | 场景                               | ATen Dispatch 调用链                                                                                                                                                                                                                                                                                                                                                                                | 正向 Dispatch 依赖的 ATen 接口                                                                      |
| -------------- | -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------- |
| `torch.vstack` | 输入均为 `>=2D`，普通 `CPU/CUDA/MPS` 张量 | `torch.vstack` -> `aten::vstack` -> `CompositeImplicitAutograd(vstack)` -> `at::native::vstack` -> `aten::atleast_2d.Sequence` -> `CompositeImplicitAutograd(atleast_2d.Sequence)` -> `at::native::atleast_2d(TensorList)`（直接返回原 tensors） -> `aten::cat(tensors, 0)` -> `CPU/CUDA/MPS` structured `cat` wrapper -> `precompute + op.meta()` -> `cat_out_cpu/cat_out_cuda/cat_out_mps`            | `aten::vstack`, `aten::atleast_2d.Sequence`, `aten::cat`                                     |
| `torch.vstack` | 含 `1D/0D` 输入，普通张量                | `torch.vstack` -> `aten::vstack` -> `CompositeImplicitAutograd(vstack)` -> `at::native::vstack` -> `aten::atleast_2d.Sequence` -> `at::native::atleast_2d(TensorList)` -> 对每个输入走 C++ helper：`1D -> aten::unsqueeze(0)`，`0D -> aten::reshape({1,1})` -> `aten::cat(tensors, 0)` -> `CPU/CUDA/MPS` structured `cat` wrapper -> `precompute + op.meta()` -> `cat_out_cpu/cat_out_cuda/cat_out_mps`  | `aten::vstack`, `aten::atleast_2d.Sequence`, `aten::unsqueeze`, `aten::reshape`, `aten::cat` |
| `torch.vstack` | 任一输入 `requires_grad=True`        | `torch.vstack` -> `aten::vstack`（无专用 Autograd 注册，直接落到 `CompositeImplicitAutograd`） -> `aten::atleast_2d.Sequence`（同样无专用 Autograd 注册） -> `[若有 1D/0D 输入，则先经 aten::unsqueeze / aten::reshape 的 view 路径]` -> `aten::cat(tensors, 0)` -> `Autograd(cat: CatBackward0)` -> redispatch -> `CPU/CUDA/MPS` structured `cat` wrapper -> `precompute + op.meta()` -> `cat_out_cpu/cat_out_cuda/cat_out_mps` | `aten::vstack`, `aten::atleast_2d.Sequence`, `aten::unsqueeze`, `aten::reshape`, `aten::cat` |
| `torch.vstack` | 使用 `out=`                        | `torch.vstack(..., out=out)` -> `aten::vstack.out` -> `CompositeImplicitAutograd(vstack.out)` -> `at::native::vstack_out` -> `aten::atleast_2d.Sequence` -> `aten::cat.out(tensors, 0, out)` -> `Autograd(cat.out)`（若输入或 `out` 需要 grad 则报错；否则 redispatch） -> `CPU/CUDA/MPS` structured `cat.out` wrapper -> `precompute + op.meta()` -> `cat_out_cpu/cat_out_cuda/cat_out_mps`                   | `aten::vstack.out`, `aten::atleast_2d.Sequence`, `aten::cat.out`                             |


## 备注

- `aten::vstack` 本身是 `CompositeImplicitAutograd` 包装，真正进入 backend 的核心计算是内层 `aten::cat` / `aten::cat.out`。
- `aten::atleast_2d.Sequence` 在实现里直接遍历输入并调用 C++ helper；只有遇到 `1D/0D` 输入时，才会进一步产生真实 ATen hop：`aten::unsqueeze` 或 `aten::reshape`。
