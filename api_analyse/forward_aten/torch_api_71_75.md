# torch API 71-75 ATen Dispatch 分析

| 接口 | 场景 | ATen Dispatch 调用链 | 正向 Dispatch 依赖的 ATen 接口 |
| --- | --- | --- | --- |
| `torch.logcumsumexp` | 稠密浮点张量，`dim` 为整数，`requires_grad=True` | `torch.logcumsumexp` -> `aten::logcumsumexp` -> `[requires_grad] AutogradCPU/CUDA/MPS`(`LogcumsumexpBackward0`) -> `CompositeExplicitAutograd`(`native::logcumsumexp`) -> 真实 runtime hop `aten::_logcumsumexp` -> CPU/CUDA/MPS backend -> `{CPU: native::_logcumsumexp_cpu -> logcumsumexp_stub -> logcumsumexp_cpu_kernel; CUDA: native::_logcumsumexp_cuda; MPS: native::_logcumsumexp_mps}` | `aten::logcumsumexp`<br>`aten::_logcumsumexp` |
| `torch.logdet` | 实数或复数方阵；`requires_grad=True` 时实际求导落在内部 `slogdet` 路径 | `torch.logdet` -> `aten::logdet` -> `CompositeImplicitAutograd`(`native::logdet`) -> 真实 runtime hop `aten::linalg_slogdet` -> `CompositeImplicitAutograd`(`native::linalg_slogdet`) -> 真实 runtime hop `aten::_linalg_slogdet` -> `[requires_grad] AutogradCPU/CUDA/MPS`(`LinalgSlogdetBackward0`) -> CPU/CUDA/MPS structured wrapper(`meta + impl`，由 `_linalg_slogdet` 的 structured schema 生成，不额外增加 runtime hop) -> `native::_linalg_slogdet_out` -> `aten::linalg_lu_factor_ex.out` + `aten::sgn` + `aten::prod` + `aten::mul.out` + `aten::abs` + `aten::log_` + `aten::sum.IntList_out` -> `{实数: aten::where; 复数: aten::log + aten::add}` | `aten::logdet`<br>`aten::linalg_slogdet`<br>`aten::_linalg_slogdet`<br>`aten::linalg_lu_factor_ex.out`<br>`aten::sgn`<br>`aten::prod`<br>`aten::mul.out`<br>`aten::abs`<br>`aten::log_`<br>`aten::sum.IntList_out`<br>`aten::where`<br>`aten::log`<br>`aten::add` |
| `torch.logit` | 稠密浮点张量，显式传 `eps`，`requires_grad=True` | `torch.logit` -> `aten::logit` -> `[requires_grad] AutogradCPU/CUDA/MPS`(`LogitBackward0`) -> CPU/CUDA/MPS backend wrapper -> `{CPU/CUDA: native::logit -> unary_op_impl_float -> logit_stub -> logit_kernel_cpu/cuda; MPS: native::logit_mps}` | `aten::logit` |
| `torch.logspace` | `start/end` 为 0-D Tensor 的 overload；能看清 overload 回落到标量工厂路径 | `torch.logspace` -> `aten::logspace.Tensor_Tensor` -> `autogradNotImplementedFallback` -> `CompositeExplicitAutograd`(`native::logspace(Tensor, Tensor)`) -> unwrap 0-D tensor 为标量 -> 真实 runtime hop `aten::logspace`(Scalar, Scalar) -> `CompositeExplicitAutograd`(`native::logspace`) -> 真实 runtime hop `aten::empty` -> 真实 runtime hop `aten::logspace.out` -> `{CPU/Meta: native::logspace_out; CUDA: native::logspace_cuda_out}` | `aten::logspace.Tensor_Tensor`<br>`aten::logspace`<br>`aten::empty`<br>`aten::logspace.out` |
| `torch.lu_solve` | 兼容旧接口；稠密 CPU/CUDA 张量，`self`/`LU_data` 参与求导 | `torch.lu_solve` -> `aten::lu_solve` -> `CompositeImplicitAutograd`(`native::lu_solve`，deprecated wrapper) -> 真实 runtime hop `aten::linalg_lu_solve(LU_data, LU_pivots, self)` -> `[requires_grad] AutogradCPU/CUDA`(`LinalgLuSolveBackward0`，`pivots` 不可导) -> CPU/CUDA structured wrapper(`meta + impl`，由 `aten::linalg_lu_solve.out` schema 生成，但这里不是额外 runtime hop) -> `native::linalg_lu_solve_out` -> `lu_solve_stub` | `aten::lu_solve`<br>`aten::linalg_lu_solve`<br>`aten::linalg_lu_solve.out` |

## 备注

- `torch.lu_solve` 是旧接口封装，真正落到后端计算的是 `aten::linalg_lu_solve`。
- `torch.logspace` 顶层走 `autogradNotImplementedFallback`，不是常规可求导算子链。
