# torch API 1-5 ATen Dispatch 分析

| 接口 | 场景 | ATen Dispatch 调用链 | 正向 Dispatch 依赖的 ATen 接口 |
| --- | --- | --- | --- |
| `torch.absolute` | 密集张量，`requires_grad=False`                          | frontend -> `aten::absolute` -> `CompositeImplicitAutograd` -> `at::native::absolute` -> 真实运行时 hop `aten::abs` -> `CompositeExplicitAutograd` -> `at::native::abs` -> 真实运行时 hop `aten::abs.out` -> `CPU/CUDA` wrapper -> `at::native::abs_out` -> `abs_stub` -> `abs_kernel` / `abs_kernel_cuda`                                                                                                          | `aten::absolute`、`aten::abs`、`aten::abs.out`                                                      |
| `torch.absolute` | 密集张量，`requires_grad=True`                           | frontend -> `aten::absolute` -> `CompositeImplicitAutograd` -> `at::native::absolute` -> `aten::abs` -> `AutogradCPU/AutogradCUDA` `VariableType::abs` -> `AbsBackward0` -> `redispatch::abs` -> `CompositeExplicitAutograd` -> `at::native::abs` -> `aten::abs.out` -> backend wrapper -> `at::native::abs_out` -> `abs_stub` -> kernel                                                                  | `aten::absolute`、`aten::abs`、`aten::abs.out`                                                      |
| `torch.absolute` | `out=` 重载                                           | frontend -> `aten::absolute.out` -> `CompositeImplicitAutograd` -> `at::native::absolute_out` -> 真实运行时 hop `aten::abs.out` -> `AutogradCPU/AutogradCUDA` `VariableType::abs_out_out` -> 若 `self/out` 需要 grad 则报错，否则 `redispatch::abs_out` -> backend wrapper -> `at::native::abs_out` -> `abs_stub` -> kernel                                                                                             | `aten::absolute.out`、`aten::abs.out`                                                              |
| `torch.addcdiv`  | CPU/CUDA，无 grad、无 autocast                          | frontend -> `aten::addcdiv` -> `CPU/CUDA` wrapper -> `op.meta()` -> `op.impl()` -> `TORCH_IMPL_FUNC(addcdiv_out)` -> `addcdiv_stub` -> `addcdiv_cpu_kernel` / `addcdiv_cuda_kernel`                                                                                                                                                                                                                       | `aten::addcdiv`                                                                                   |
| `torch.addcdiv`  | CPU/CUDA，`requires_grad=True`                       | frontend -> `aten::addcdiv` -> `AutogradCPU/AutogradCUDA` `VariableType::addcdiv` -> `AddcdivBackward0` -> `redispatch::addcdiv(after_autograd)` -> `CPU/CUDA` wrapper -> `op.meta()` -> `op.impl()` -> `addcdiv_stub` -> backend kernel                                                                                                                                                                  | `aten::addcdiv`                                                                                   |
| `torch.addcdiv`  | `out=` 重载                                           | frontend -> `aten::addcdiv.out` -> `Autograd` wrapper；若任一输入或 `out` 需要 grad 则 `throw_error_out_requires_grad("addcdiv")`，否则 `redispatch::addcdiv.out` -> `CPU/CUDA/Meta/MPS` backend wrapper -> `op.meta()` -> `op.impl()` -> CPU/CUDA: `addcdiv_stub` -> kernel；MPS: `addcdiv_out_mps`                                                                                                                    | `aten::addcdiv.out`                                                                               |
| `torch.addcdiv`  | CUDA autocast                                       | frontend -> `aten::addcdiv` -> `AutocastCUDA(promote)` -> `promote_type + cached_cast` -> `redispatch::addcdiv` -> 若需要梯度再进入 `AutogradCUDA` -> `CUDA` wrapper -> `op.meta()` -> `op.impl()` -> `addcdiv_stub` -> `addcdiv_cuda_kernel`                                                                                                                                                                     | `aten::addcdiv`                                                                                   |
| `torch.addcdiv`  | 无专用 backend wrapper 的 fallback backend              | frontend -> `aten::addcdiv` -> `CompositeExplicitAutogradNonFunctional` -> `op.meta()` -> 真实运行时 hop `at::addcdiv_outf(...)` -> `aten::addcdiv.out` -> lower backend `.out` kernel                                                                                                                                                                                                                         | `aten::addcdiv`、`aten::addcdiv.out`                                                               |
| `torch.addcmul`  | CPU/CUDA，无 grad                                     | frontend -> `aten::addcmul` -> `CPU/CUDA` wrapper -> `op.meta()` -> `op.impl()` -> `TORCH_IMPL_FUNC(addcmul_out)` -> `addcmul_stub` -> `addcmul_cpu_kernel` / `addcmul_cuda_kernel`                                                                                                                                                                                                                       | `aten::addcmul`                                                                                   |
| `torch.addcmul`  | CPU/CUDA，`requires_grad=True`                       | frontend -> `aten::addcmul` -> `AutogradCPU/AutogradCUDA` `VariableType::addcmul` -> `AddcmulBackward0` -> `redispatch(after_autograd)` -> `CPU/CUDA` wrapper -> `op.meta()` -> `op.impl()` -> `addcmul_stub` -> backend kernel                                                                                                                                                                           | `aten::addcmul`                                                                                   |
| `torch.addcmul`  | `out=` 重载                                           | frontend -> `aten::addcmul.out` -> `Autograd` wrapper；若任一输入或 `out` 需要 grad 则 `throw_error_out_requires_grad("addcmul")`，否则 `redispatch::addcmul.out` -> backend `.out` wrapper -> `op.meta()` -> `op.impl()` -> CPU/CUDA: `addcmul_stub` -> kernel；MPS: `addcmul_out_mps`                                                                                                                                 | `aten::addcmul.out`                                                                               |
| `torch.addcmul`  | 无专用 backend wrapper 的默认 backend 路径                  | frontend -> `aten::addcmul` -> `CompositeExplicitAutogradNonFunctional` -> `op.meta()` -> 真实运行时 hop `at::addcmul_outf(...)` -> `aten::addcmul.out` -> backend `.out` wrapper -> `op.meta()` -> `op.impl()` -> `addcmul_stub` 或 `addcmul_out_mps`                                                                                                                                                          | `aten::addcmul`、`aten::addcmul.out`                                                               |
| `torch.addcmul`  | CUDA/MPS autocast                                   | frontend -> `aten::addcmul` -> `Autocast(promote)` -> `cached_cast` -> `redispatch::addcmul` -> 若需要梯度再进入 `Autograd` -> backend wrapper -> `op.meta()` -> `op.impl()` -> stub / MPS impl                                                                                                                                                                                                                   | `aten::addcmul`                                                                                   |
| `torch.addr`     | CPU/CUDA，eager，`requires_grad=False`                | frontend -> `Tensor::addr` -> `at::_ops::addr::call` -> dispatcher -> `CPU/CUDA` wrapper -> `at::native::addr` -> `build_addr_iter` -> `addr_stub(device_type, iter, beta, alpha)` -> `addr_kernel` / `addr_kernel_cuda`                                                                                                                                                                                  | `aten::addr`                                                                                      |
| `torch.addr`     | CPU/CUDA，eager，`requires_grad=True`                 | frontend -> `Tensor::addr` -> `at::_ops::addr::call` -> `AutogradCPU/AutogradCUDA` `VariableType::addr` -> `AddrBackward0` -> `at::redispatch::addr(after_autograd)` -> `CPU/CUDA` wrapper -> `at::native::addr` -> `addr_stub` -> backend kernel                                                                                                                                                         | `aten::addr`                                                                                      |
| `torch.addr`     | CUDA autocast                                       | frontend -> `Tensor::addr` -> `at::_ops::addr::call` -> `AutocastCUDA(lower_precision_fp)` -> `cached_cast(lower_precision)` -> `redispatch::addr` -> 若需要梯度再进入 `AutogradCUDA::addr` -> `CUDA` wrapper -> `at::native::addr` -> `addr_stub` -> `addr_kernel_cuda`                                                                                                                                          | `aten::addr`                                                                                      |
| `torch.addr`     | CompositeExplicitAutograd fallback backend          | frontend -> `Tensor::addr` -> `at::_ops::addr::call` -> `CompositeExplicitAutograd` -> `at::native::math_addr` -> 真实运行时 hop `aten::outer(vec1, vec2)` -> 按 `alpha/beta` 条件再做 `aten::mul / aten::add` -> `aten::to(result_type)`                                                                                                                                                                                               | `aten::addr`、`aten::outer`、`aten::mul`、`aten::add`、`aten::to`                                     |
| `torch.addr`     | `out=` 重载                                           | frontend -> `aten::addr.out` -> `VariableType::addr_out_out`；若任一输入或 `out` 需要 grad 则报错，否则 `redispatch::addr.out` -> direct backend wrapper -> `at::native::addr_out` -> `addr_stub` -> backend kernel；Composite fallback 时 `math_addr_out` 会先真实调用一次 `aten::addr(...)`，再把结果别名写回 `out`                                                                                                                    | `aten::addr.out`；composite `out` 路径还涉及 `aten::addr`                                 |
| `torch.adjoint`  | 普通 dense/strided，非复数，`ndim >= 2`，`requires_grad` 任意 | frontend -> `aten::adjoint` -> `CompositeImplicitAutograd` -> `at::native::adjoint` -> `_adjoint` -> `aten::transpose.int` -> `CompositeExplicitAutograd` -> `at::native::transpose` -> `aten::as_strided`                                                                                                                                                                                                | `aten::adjoint`、`aten::transpose.int`、`aten::as_strided`                                          |
| `torch.adjoint`  | 普通 dense/strided，复数，`ndim >= 2`，`requires_grad` 任意  | frontend -> `aten::adjoint` -> `CompositeImplicitAutograd` -> `at::native::adjoint` -> `_adjoint` -> `aten::transpose.int` -> `CompositeExplicitAutograd` -> `at::native::transpose` -> `aten::as_strided` -> `aten::conj` -> `CompositeImplicitAutograd` -> `at::native::conj` -> `Tensor::conj()` -> `aten::_conj` -> `CompositeExplicitAutograd` -> `at::native::_conj` -> `aten::alias` + `_set_conj` | `aten::adjoint`、`aten::transpose.int`、`aten::as_strided`、`aten::conj`、`aten::_conj`、`aten::alias` |
| `torch.adjoint`  | 0-D 复数标量                                            | frontend -> `aten::adjoint` -> `CompositeImplicitAutograd` -> `at::native::adjoint` -> `_adjoint` -> `aten::conj` -> `CompositeImplicitAutograd` -> `at::native::conj` -> `Tensor::conj()` -> `aten::_conj` -> `CompositeExplicitAutograd` -> `at::native::_conj` -> `aten::alias` + `_set_conj`；同时有 0-D deprecation warning                                                                              | `aten::adjoint`、`aten::conj`、`aten::_conj`、`aten::alias`                                          |
| `torch.adjoint`  | 0-D 非复数标量                                           | frontend -> `aten::adjoint` -> `CompositeImplicitAutograd` -> `at::native::adjoint` -> `_adjoint` -> 直接返回 `self`；无后续 inner ATen hop；同时有 0-D deprecation warning                                                                                                                                                                                                                                           | `aten::adjoint`                                                                                   |
| `torch.adjoint`  | 1-D tensor                                          | frontend -> `aten::adjoint` -> `CompositeImplicitAutograd` -> `at::native::adjoint` -> `_adjoint` -> `TORCH_CHECK` 报错；无后续 inner ATen hop                                                                                                                                                                                                                                                                  | `aten::adjoint`                                                                                   |
