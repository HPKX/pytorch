# torch API 111-115 ATen Dispatch 分析

| 接口 | 场景 | ATen Dispatch 调用链 | 正向 Dispatch 依赖的 ATen 接口 |
| --- | --- | --- | --- |
| `torch.nn.MaxPool2d` | 默认 `return_indices=False`，普通 CPU/CUDA 张量 | `nn.MaxPool2d.forward` -> `F.max_pool2d` -> `torch.max_pool2d` -> `aten::max_pool2d` -> `Autograd(VariableType::max_pool2d)` -> `CompositeImplicitAutograd(native::max_pool2d)` -> `aten::max_pool2d_with_indices` -> CPU/CUDA structured wrapper（`meta`+`impl`） -> `max_pool2d_with_indices_out_cpu/cuda` -> 取 `output` | `aten::max_pool2d`<br>`aten::max_pool2d_with_indices` |
| `torch.nn.MaxPool3d` | 默认 `return_indices=False`，普通 CPU/CUDA 张量 | `nn.MaxPool3d.forward` -> `F.max_pool3d` -> `torch.max_pool3d` -> `aten::max_pool3d` -> `CompositeImplicitAutograd(native::max_pool3d)` -> `aten::max_pool3d_with_indices` -> `Autograd(VariableType::max_pool3d_with_indices)` -> CPU/CUDA backend wrapper -> `max_pool3d_with_indices_cpu/cuda` -> 取 `output` | `aten::max_pool3d`<br>`aten::max_pool3d_with_indices` |
| `torch.nn.MaxUnpool1d` | 标准前向，注意 1d 通过 2d 实现 | `nn.MaxUnpool1d.forward` -> `F.max_unpool1d` -> `aten::unsqueeze`（`input/indices`） -> `torch._C._nn.max_unpool2d` -> `aten::max_unpool2d` -> `Autograd(VariableType::max_unpool2d)` -> CPU/CUDA/MPS backend wrapper -> `max_unpooling2d_forward_cpu/cuda/mps` -> `aten::squeeze` | `aten::unsqueeze`<br>`aten::max_unpool2d`<br>`aten::squeeze` |
| `torch.nn.MaxUnpool3d` | 标准前向 | `nn.MaxUnpool3d.forward` -> `F.max_unpool3d` -> `torch._C._nn.max_unpool3d` -> `aten::max_unpool3d` -> `Autograd(VariableType::max_unpool3d)` -> CPU/CUDA/MPS backend wrapper -> `max_unpooling3d_forward_cpu/cuda/mps` | `aten::max_unpool3d` |
| `torch.nn.MultiLabelMarginLoss` | 常见前向，`input.requires_grad=True` | `nn.MultiLabelMarginLoss.forward` -> `F.multilabel_margin_loss` -> `torch._C._nn.multilabel_margin_loss` -> `aten::multilabel_margin_loss` -> `CompositeImplicitAutograd(native::multilabel_margin_loss)` -> `aten::multilabel_margin_loss_forward` -> `Autograd(VariableType::multilabel_margin_loss_forward)` -> CPU/CUDA backend wrapper -> `multilabel_margin_loss_forward_cpu/cuda` -> 取 `output` | `aten::multilabel_margin_loss`<br>`aten::multilabel_margin_loss_forward` |
