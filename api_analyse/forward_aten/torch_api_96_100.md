# torch API 96-100 ATen Dispatch 分析

| 接口 | 场景 | ATen Dispatch 调用链 | 正向 Dispatch 依赖的 ATen 接口 |
| --- | --- | --- | --- |
| `torch.nn.GRUCell` | dense CPU/非 CUDA，batched 输入 | `Module.forward` -> `_VF.gru_cell` -> `aten::gru_cell` -> `CompositeImplicitAutograd::native::gru_cell` -> `native::GRUCell<CellParams>` -> `aten::linear(input,w_ih,b_ih)` + `aten::linear(hx,w_hh,b_hh)` -> `aten::unsafe_chunk` -> `aten::add_`/`aten::sigmoid_`/`aten::mul_`/`aten::tanh_`/`aten::sub` -> 输出 | `aten::gru_cell`, `aten::linear`, `aten::unsafe_chunk`, `aten::add_`, `aten::sigmoid_`, `aten::mul_`, `aten::tanh_`, `aten::sub` |
| `torch.nn.GRUCell` | dense CUDA，走 fused GRU cell | `Module.forward` -> `_VF.gru_cell` -> `aten::gru_cell` -> `CompositeImplicitAutograd::native::gru_cell` -> `native::GRUCell<CellParams>` -> `aten::t` + `aten::matmul`（input/hx 各一次）-> `aten::_thnn_fused_gru_cell` -> `AutogradCUDA` -> `CUDA::_thnn_fused_gru_cell_cuda` | `aten::gru_cell`, `aten::t`, `aten::matmul`, `aten::_thnn_fused_gru_cell` |
| `torch.nn.GaussianNLLLoss` | `var` 为可 broadcast 的 tensor，`reduction='mean'` | `Module.forward` -> `F.gaussian_nll_loss` -> 无专用 loss schema，直接由基础 ATen 组合 -> `aten::lt.Scalar` + `aten::any` 校验非负 -> 可选 `aten::unsqueeze` -> `aten::clone` -> `NoGradGuard + aten::clamp_` -> `aten::sub` -> `aten::pow.Tensor_Scalar` -> `aten::div.Tensor` -> `aten::log` -> `aten::add.Tensor` -> `aten::mul.Scalar` -> `aten::mean` | `aten::lt.Scalar`, `aten::any`, `aten::unsqueeze`, `aten::clone`, `aten::clamp_`, `aten::sub`, `aten::pow.Tensor_Scalar`, `aten::div.Tensor`, `aten::log`, `aten::add.Tensor`, `aten::mul.Scalar`, `aten::mean` |
| `torch.nn.HardTanh` | `inplace=False` | `Module.forward` -> `F.hardtanh` -> `torch._C._nn.hardtanh` -> `aten::hardtanh` -> `AutogradCPU/CUDA/MPS` -> backend `native::hardtanh` -> `aten::empty_like` -> `aten::hardtanh.out` -> backend `native::hardtanh_out` -> `aten::clamp.out` | `aten::hardtanh`, `aten::empty_like`, `aten::hardtanh.out`, `aten::clamp.out` |
| `torch.nn.HardTanh` | `inplace=True` | `Module.forward` -> `F.hardtanh(..., inplace=True)` -> `torch._C._nn.hardtanh_` -> `aten::hardtanh_` -> `AutogradCPU/CUDA/MPS` -> backend `native::hardtanh_` -> 内部复用 `aten::hardtanh.out(self=self)` -> backend `native::hardtanh_out` -> `aten::clamp.out` | `aten::hardtanh_`, `aten::hardtanh.out`, `aten::clamp.out` |
| `torch.nn.HingeEmbeddingLoss` | 默认 `margin=1.0`，`reduction='mean'` | `Module.forward` -> `F.hinge_embedding_loss` -> `aten::hinge_embedding_loss` -> `CompositeImplicitAutograd::native::hinge_embedding_loss` -> `aten::zeros_like` -> `aten::rsub.Scalar` 计算 `margin-self` -> `aten::clamp_min_` / `aten::clamp_min` -> `aten::where` 两次分流 -> `aten::add` -> `aten::mean` | `aten::hinge_embedding_loss`, `aten::zeros_like`, `aten::rsub.Scalar`, `aten::clamp_min_`, `aten::clamp_min`, `aten::where`, `aten::add`, `aten::mean` |
| `torch.nn.HuberLoss` | 模块默认路径（`weight=None`），`reduction='mean'` | `Module.forward` -> `F.huber_loss` -> `aten::broadcast_tensors` -> `torch._C._nn.huber_loss` -> `aten::huber_loss` -> `AutogradCPU/CUDA/MPS` -> backend `native::huber_loss` / `huber_loss_mps` -> `aten::empty_like` -> `huber_stub` -> `aten::mean` | `aten::broadcast_tensors`, `aten::huber_loss`, `aten::empty_like`, `aten::mean` |

## 备注
- `torch.nn.GaussianNLLLoss` 没有单独的 `aten::gaussian_nll_loss`；模块 forward 本质是 `torch.nn.functional.gaussian_nll_loss` 对基础 ATen 算子的 Python composite。
- 基准清单里的标准接口名是 `torch.nn.HardTanh`；源码类名写作 `Hardtanh`，这里按基准清单对齐输出。
