## 备注

- `Softmin`、`Softsign`、`Tanhshrink` 在 `nn`/`F` 层都是 Python 组合包装，前向不会进入同名单独 `aten::softmin/softsign/tanhshrink` 内核。
- `Transformer` 按内置 encoder/decoder 分析；`TransformerDecoder` 按 `decoder_layer=nn.TransformerDecoderLayer` 分析。若传入自定义子模块，链路会被覆盖。
- `aten::scaled_dot_product_attention` 本身是 selector op，真实后端由 device、dtype、mask、dropout 等条件动态选择。
- 表中以前向主链为主；若 `requires_grad=True`，`aten::_softmax`、`aten::linear`、`aten::native_layer_norm` 以及各 SDPA backend 还会先经过 `Autograd{CPU/CUDA}` 包装再 redispatch。
